# Controller Stutter and Input Lag Notes (Windows 10/11)

* Microsoft GameInput Stutters (Windows 10/11): Background components like Microsoft GameInput can cause severe frame drops and controller stuttering in games. You can temporarily disable or clean up GameInput services via `services.msc` or reinstall the controller driver. [[1](https://learn.microsoft.com/en-us/answers/questions/5569976/fps-drop-and-stutters-when-using-controller-but-no), [2](https://www.reddit.com/r/halo/comments/1ntrcgn/controller_on_pc_are_causing_frame_drops_and/)]
* Outdated Drivers and Firmware: Old USB, Bluetooth, or controller firmware leads to input delay. Update your controller via the manufacturer app (such as the Xbox Accessories app) and check Device Manager for driver updates. [[1](https://rushcontroller.com/blogs/technical-support/gaming-controller-input-lag), [2](https://customercare.scufgaming.com/hc/en-us/articles/4408280862861-How-to-Fix-Input-Lag-on-PC-Wired), [3](https://usekudu.com/guides/gaming/fix-controller-input-lag-on-windows-pc)]
